# Avalon Northwestern Branding

This set of files extends Avalon, Blacklight, and Bootstrap styling to apply Northwestern branding across the application.

## Usage

Append the `@import` to **app/assets/stylesheets/application.scss**

```css
/*
 *
 * Northwestern University Avalon
 * -------------------------------------------------------------
 * Custom branding for Avalon to override Avalon, Blacklight,
 * and Bootstrap styling. This should be included at the bottom
 * of the app/assets/stylesheets/application.scss file
 *
 */

@import 'northwestern';
```
